# 共同発起人として、加わりませんか

## Youth GCC と、その最初の課題「減らすほど得をする社会」を、一緒につくる



---

### 要点

- **状況**：何十年もの努力にもかかわらず、気候危機の曲線は曲がっていません。善意が足りないからではありません。国境を越えて未来のために語る担い手、市民の意思を意思決定につなぐ回路、そして移行先の具体的な設計図がないからです。
- **つくろうとしているもの**：3つの提案からなるパッケージです。**Youth GCC**（誰が担うか）、**Global Citizen Will Platform**（市民の意思をどう意思決定につなぐか）、**Planetary OS**（減らすほど得をする、政策の設計図）。
- **お願いしたいこと**：請願への署名ではありません。**共同発起人として加わり**、最初の段階から、一緒に形づくり、試し、ともに担っていただくことです。

---

## 1. なぜ今、呼びかけるのか

何年ものあいだ、何百万もの若者が街頭に立ってきました。その努力は社会の議論を変えてきました。けれども、それぞれの活動は国や団体ごとに散らばっていて、意思決定が行われる場までは、なかなか届いていません。

それを変えられるものが2つあると、私たちは考えています。

- **具体的な問い**：指導者に「もっとやってほしい」と求めるのではなく、動く設計図を示し、**「この仕組みにつなぎますか」**と問うことです。最初の課題は **Planetary OS** です。化石燃料に一方向にしか下がらない上限をかけ、その収入の大半を市民に直接還すことで、多くの世帯の手取りがプラスになる仕組みです。
- **共有された回路**：それぞれの運動が単独で動くのではなく、開かれたプラットフォームで力をつなぐことです。どの団体も、自分たちの名前と活動はそのまま保ちます。

これは、特定の一つの団体のプロジェクトではありません。最初の日から、**より広い運動によって形づくられ、その運動のものになる**ように設計しています。だからこそ、設計がまだ開かれている今、共同発起人を募っています。

---

## 2. 共同発起人になるとは

| できること | 具体的には |
|---|---|
| **設計を形づくる** | 公開を広げる前に、パッケージと提案A・B・Cを読み、意見を寄せる |
| **自分たちの場で試す** | 還元シミュレーターや Planetary OS の資料を自分たちの活動で使い、何が届くかを教えてもらう |
| **成果をともに担う** | 共同設立の協力団体として名前が記される。成果は、特定の誰かの名前ではなく、共有の規格として公開する |
| **独自性を保つ** | 団体の名前、優先課題、活動はそのまま。加わることは、統合することではない |

共同発起人になっても、お金の負担や、他の活動を制限する約束はありません。どこまで関わるかは、ご自身で決められます。

---

## 3. 呼びかけたい人

- 🌐 **若者主導の団体と気候の運動**：地域での活動を、地球規模の取り組みにつなげたい団体
- 🛠️ **シビックテックの開発者とプラットフォーム**：熟議のツール、支持のダッシュボード、シミュレーターの開発を手伝える人
- 🔬 **研究者と専門家**：経済学、気候科学、法律、熟議民主主義などの分野で、Planetary OS の Standard を検証し、ともに執筆する人
- 🕊️ **経験のある指導者、先住民族と宗教の指導者**：助言の層として、助言と経験を寄せる人（決定は若者が担います）

団体だけでなく、個人の方も歓迎します。
