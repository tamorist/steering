# このサイトについて

**限界の内側で、舵を取る**（Steering Within Limits）は、文明の転換に向けた3つの提案と、その背景にある考え方、そしてそれを試すための道具をまとめたサイトです。

## 位置づけ

ここにあるものは、すべて**草案**です。制度の名前・比率・数値は、すべて一例です。方向性を示すもので、最終的な設計ではありません。専門家の検証、市民の熟議、試行を通じて書き直していくことを前提としています。

## 言語

英語版が正本で、日本語のページはその対訳です。内容に食い違いがある場合は、英語版を優先します。（日本語の連載「地球のOSを書き換える」は、日本の読者向けの読み物で、日本の試算などを含みます。）

## 事実と数値

事実と統計は、2026年10月に公開の資料（国連、IMF、IPCC、Global Carbon Project、NOAA、FAO、World Inequality Report など）で確認しました。概数は丸めています。誤りを見つけた場合は、お知らせください。

## AIの使い方

この提案は、一人の個人が、生成AIを大きく活用して作りました。調べもの、構成、文章、図、シミュレーターのコードに、生成AIを使っています。何を書くか、何を採用するかは、すべて筆者が判断し、責任を持ちます。

これは、この提案自体が示そうとしていることの、小さな実例でもあります。これまで、制度の設計図を描くには、研究機関や政府のような大きな組織が必要でした。AIは、一人の市民が、そうした叩き台をつくり、誰でも検証できる形で公開することを可能にします。この提案の原則は「AIは支えるが、決めない」です。このサイトも同じで、AIは作るのを支えましたが、何が望ましいかを決めるのは、これを読み、検証し、熟議する人々です。

ですから、この提案は、使える設計図かどうかで判断してください。事実と数値は公開の資料で確かめていますが、誤りは残っているはずです。見つけた点や、よりよい案があれば、お知らせください。

## プライバシー

Cookie は使っていません。このサイトでは、Cookie を使わず個人を特定しないアクセス解析ツール GoatCounter で、ページごとの閲覧数だけを数えています。
