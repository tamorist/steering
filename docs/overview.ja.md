# 限界の内側で、舵を取る
### 文明の転換に向けた3つの提案 ―― 1ページ概要


!!! info "このページについて"
    要点だけを、約7分で読めるようにまとめたものです。全体を理由とともに理解したい方は、「はじめての方へ」[→](start.md)（約45分）へ。

**問題**：何十年もの努力にもかかわらず、気候をはじめとする地球規模のリスクの曲線は曲がっていません。原因は、努力や善意や技術の不足ではありません。拡大し続けるように作られた経済と、国家を単位とする政治という文明のOSが、もともと想定していなかった限界に達しているのです。効率化の成果は過剰な競争に飲み込まれ、恩恵は上に流れ、地球の境界は越えられつつあります。一人ひとりが合理的に行動するほど、全体として共倒れになっています。

**なぜ今か**：舵を取らずに成長してきた文明は、**限界の内側で舵を取る**ことを学ばなければなりません。地球の境界は厳格なガードレールとして守り、その内側は自由にし、データに基づいて絶えず修正し、目標は民主的に決める。これは中央計画でも、市場原理主義でもありません。そのための道具は、今そろっています。地球のデータ、デジタルの決済、AIによる翻訳、市民会議です。危機は来ます。そのときの対応の速さは、動く代わりの仕組みが用意されているかどうかで決まります。

**3つの空白と、3つの提案**

| | 空白 | 提案 | ひとことで |
|---|---|---|---|
| **A** | 国境を越えて、未来のために語る担い手がいない | **Youth GCC** | 若者が主導する地球市民会議。世界市民会議、世界政策機構、世界政策実証局を備える |
| **B** | 散らばった市民の意思を、意思決定につなぐ回路がない | **Global Citizen Will Platform** | 既存の運動の連合。支持を目に見える形にし、政府・裁判所・選挙・市場につなぐ |
| **C** | 移行先の設計図がない | **Planetary OS** | 減らすほど得をする動作ルール。一方向の上限、収入の9割を市民に還元、過去の負債の分かち合い、参加すると得をするクラブ |

**どう組み合わさるか**：Youth GCC は、Planetary OS を最初の課題として立ち上がります。世界市民会議が Standard を検証し、世界政策機構が起草し、世界政策実証局が試行を担います。プラットフォームは、還元シミュレーターと一つの問いを政治に届けます。「動いてください」ではなく、**「この仕組みにつなぎますか」**という問いです。担い手のない設計図は紙の上にとどまり、設計図のない担い手は方向を見失います。両者とも、意思決定に届く回路を必要とします。

**原則**：国家や国連に取って代わるのではなく、補います。正統性は宣言するものではなく、開かれた参加と独立した評価で積み重ねるものです。専門家は判断材料を示し、市民が価値を決めます。AIは支えますが、決めません。すべての設計は草案です。

**最初の18か月（第1段階）**：Planetary OS の Standard の第1版、公開の還元シミュレーター、共同設立者と協力団体による Youth GCC の立ち上げ、最初の市民会議による検証、試行の受け入れ先との協議。
