# 世界市民ガバナンス憲章
### 国家の上ではなく、国家と並ぶ「世界市民の政治の回路」

**第2版**（草案、2026年10月）


---

## この憲章の位置づけ

この憲章は、**提案A：Youth GCC** が土台とする制度の設計を示すものです。提案Aは、誰がそれを担うかを示します。この憲章は、制度そのものと、それを民主的に保つための原則を示します。

- **提案A：Youth GCC**[→](../proposals/a-youth-gcc.md)：この回路を立ち上げ、運営する、若者主導の組織
- **提案B：Global Citizen Will Platform**[→](../proposals/b-platform.md)：開かれた参加の層
- **提案C：Planetary OS**[→](../proposals/c-summary.md)：この回路で最初に扱う政策の設計

以下の名前・規模・数値は、すべて**一例**です。方向性を示すもので、試され、見直されることを前提としています。

---

## 1. なぜ、この憲章が必要なのか

国家は欠かせない制度です。人々の自由、安全、福祉、文化を守っています。けれども、人類の未来を左右する問題の多くは、どの国も一国だけでは解決できません。気候変動、高度なAI、生物技術、核兵器、感染症、海洋、国際金融は、どれも国境を越えて影響し合います。

今の国際的な制度は、主に国家どうしの利害を調整しています。それは大切な仕事です。けれども、国家の利益と人類全体の利益が一致しないとき、世界全体の立場から政策の選択肢をつくり、試し、市民が判断できるようにする、常設の制度はありません。

この憲章は、その空白を埋めることを目指します。国家をなくすことも、国際機関を否定することも、企業・大学・市民社会を締め出すこともしません。それらとは別に、**世界市民が問題を提起し、選択肢をつくって試し、熟議し、民主的に承認する**回路を加えます。

---

## 2. 3つの原則

### 原則①　世界市民は、政治の主体である

人類に共通する問題について、すべての人は、国籍とは関係なく、世界市民としての利益を持っています。その利益は、国家の利益と同じではありません。そのため、国家を代表する機関と、世界市民を代表する機関は分けます。国連などの政府間機関は、国家どうしの調整を担います。ここで示す回路は、人類の長期的な利益のための政策づくりを担います。両者は対立するためではなく、互いに牽制し、協力するためにあります。

### 原則②　「選択肢をつくること」と「決めること」を分ける

民主主義は、投票だけではありません。**何を選択肢として示すかは、それ自体が一つの権力です。** そこで、次の一連の流れ全体を、民主的な制度の内側に置きます。

1. 問題を見つける
2. 問題を定める
3. 複数の選択肢をつくる
4. それぞれを科学的・経済的に検証する
5. 市民が熟議する
6. 市民が選ぶ
7. 実際に試す
8. 結果を評価する
9. 政策を改める

### 原則③　「政府」ではなく「政策をつくる機関」として始める

最初、この回路は**国家に対する強制力を持ちません**。その代わりに、世界市民が民主的につくった政策に、国家と国際機関が**公開で応答し**、採用・修正・拒否の理由を説明するよう求めます。国家に「何をすべきか」を命じることから始めるのではなく、提案を示し、理由を求めることから始めます。

## 3. 機関

| 機関 | 役割（一例） |
|---|---|
| **世界市民会議** | 世界人口の統計的な縮図となるよう、すべての世代からくじ引きで選ぶ市民。地域、年齢、性別、所得、教育、都市と農村などを考慮し、国籍ごとの割り当てはしない。常設の中核は500〜2,000人程度で、毎年一部を入れ替える。重要な問題では、より大規模なオンラインの参加で補う。報酬、翻訳、通信設備、学習支援、保育・介護の支援、障害のある人への支援を保障し、所得や住む場所で参加が左右されないようにする |
| **世界政策機構** | どの国家、政府、政党、企業、国際機関の支配も受けない。単一の国家や企業からの資金は一定の割合までとし、資金はすべて公開する。課題ごとに**少なくとも3つの実行可能な選択肢**をつくり、費用、効果、分配と地域への影響、実施の可能性、リスク、副作用、長期的な影響を公開する |
| **世界政策実証局** | 世界政策機構の中に置く、独立した実証の部門。政策は**できる限り試してから広げる**。シミュレーション、小規模な試行、複数の地域での比較、独立した評価、世界市民会議による再評価を行う。成功だけでなく失敗も、みんなで共有する知識として公開する |
| **世界市民政策評議会** | 世界市民会議と世界政策機構をつなぐ常設の機関。市民の代表、科学者、技術者、経済学者、法学者、倫理学者、市民社会、当事者、実務家で構成する。世界市民会議は大きく、定期的に開かれ、世界政策機構は専門家の機関なので、両者が継続して一緒に働く場が必要になる。評議会は、問いを立て、選択肢が公平で分かりやすいかを確かめ、会議と会議のあいだの継続性を保つ。**最終的な民主的権限は、市民の代表にある。** 専門家は、何が可能か、何が起きうるか、どんな副作用がありうるかを示し、何が望ましいかは決めない |
| **独立した監査** | 手続き、財務、利益相反、参加の公平さを確かめ、結果を公開する |

**複数の選択肢の例**：気候について、世界政策機構は、たとえば炭素価格中心型、世界炭素配当型、公共投資・配給型、市場・規制混合型といった案を示します。**Planetary OS** は、このうち世界炭素配当型を具体的に設計したもので、ほかの案と並べて比べます。

4つの型は、たとえば次のようなものです。

- **炭素価格中心型**：炭素税や排出量取引で炭素に価格をつけ、収入の使い道は各国に任せる
- **世界炭素配当型**：収入を、市民に直接還す
- **公共投資・配給型**：公共の投資で低炭素のインフラを整え、限られた資源は必要に応じて割り当てる
- **市場・規制混合型**：効率の基準や廃止の期限などの規制と、市場の仕組みを組み合わせる

## 4. 政策形成のサイクル

主要な政策について、機関は次のサイクルで動きます。

| 段階 | 内容 |
|---|---|
| 1. 市民が課題を提起する | 一定の支持を得た課題は、正式に取り上げる |
| 2. 根拠を整理する | 世界政策機構が、科学的な知見、既存の政策、モデル、技術的な可能性、倫理的な論点を整理する |
| 3. 選択肢をつくる | 必ず複数。単一の「正解」は示さない |
| 4. 選択肢を比べる | 経済モデル、気候モデル、AIを使ったシミュレーションで比べる。**モデル、データ、前提はすべて公開し**、AIの出力だけを決定の根拠にはしない |
| 5. 世界市民会議が熟議する | 市民が専門家の説明を聞き、質問し、話し合う |
| 6. 世界市民会議が決める | 推奨案、代替案、少数意見、不確実性を含む提言を採択する |
| 7. 必要なら世界市民投票 | 重大な問題では、オンライン投票で世界市民会議を補う。ただし、熟議を経た案についてだけ |
| 8. 試す | 世界政策実証局が、試せるものを試す |
| 9. 国際的な制度にする | 結果を、各国の政府と議会、EUなどの地域機構、国連、国際機関に届ける |

## 5. 国連・国家・企業との関係

**国連**：国連は、世界市民に代わって世界市民の意思を決めることはしません。国家どうしの調整と、国際的な実装を担います。世界市民会議が合意した基準を満たす政策を採択した場合、国連総会と関連機関には、それを正式に審議してもらいます。国連や加盟国がそれを拒否する場合は、その理由を公開するよう求めます。こうすることで、世界市民の側は、拒否権を持たなくても、政策をつくる力と、それにともなう正統性を持つことができます。

**国家**：国家は参加できますが、機関を支配することはできません。

**企業**：企業は、知識、技術、実装の力を提供するステークホルダーとして参加できます。ただし、**市民の代表の枠は持ちません**。企業は企業として、市民は市民として参加します。企業から提供された資金、データ、研究は公開し、議題、研究結果、投票を左右するために使ってはなりません。

## 6. 民主的な正統性を守る

このような機関そのものが、新しいエリート支配になるおそれがあります。それを防ぐため、7つのしくみを組み込みます。

1. **任期制**：同じ人が長く権力を持たない。
2. **くじ引きによる選出**：重要な市民の代表は、選挙ではなく、くじ引きで選ぶ。
3. **完全な公開**：資料、方法、資金、投票結果を公開する。
4. **少数意見の記録**：多数決で、少数意見を消さない。
5. **外部の監査**：独立した機関が監査する。
6. **権力の分立**：研究、熟議、実証、監査、国際交渉を、一つの機関に集めない。
7. **下からの改革**：市民が、制度そのものの改革を提案できる。

そして何より、**人類の利益を、誰かが独占して定義してはなりません。** 人類の利益は、続いていく民主的な熟議の中で形づくられ、見直されていく仮説として扱います。科学者だけでも、市民だけでも、政府、企業、AIだけでもなく、それぞれが違う役割を持ちます。

## 7. 小さく始める

これを一度に世界規模で完成させる必要はありません。この回路は、一つの具体的な課題で、政策のサイクルを一通り動かすことから始めます。

**最初の課題：気候**：パッケージでは、最初に気候政策についての国際的な市民会議を開きます。世界政策機構の作業部会が、Planetary OS の Standard と別の選択肢を起草し、世界市民会議がそれを熟議します。世界政策実証局は還元シミュレーター[→](../tools/simulator.md)を運用し、小規模な試行を準備します。全体の過程は、独立した評価で確かめます。

**次に：Global AI Citizens' Assembly（世界AI市民会議）**

世界の各地域から無作為に選ばれた数百〜1,000人程度の市民が、6〜12か月かけて、一つの問いを熟議します。*高度なAIのリスクと利益をふまえ、世界はどのようなAIの統治の制度をつくるべきか。* 通訳、科学の学習、専門家との対話、AIによる資料の整理、政策のシミュレーションの支えを受けて、たとえば次のような成果をまとめます。

- AIの原則
- AIの国際的な規制の案
- AIの事故や危険な能力を見守る国際的なしくみ
- 計算資源やデータセンターについてのルール
- AIの安全の研究への公共の投資
- 国家・企業・国際機関の役割の分担

成果は、各国政府、国連、AI企業、研究機関に届けます。

協力者と資源がそろえば、気候の市民会議と並行して進めることもできます。

## 8. 長期的に考えうる道筋

十分な実績を積んだあとに、この回路は段階的に発展しうるものです。

| 段階 | 役割 |
|---|---|
| 1 | 政策を提言する機関 |
| 2 | 国際的な政策をつくる機関 |
| 3 | 国際条約づくりに正式に参加する機関 |
| 4 | 世界市民議会 |

長い目で見れば、これは**二院型の世界政治**につながりえます。各国政府で構成する国家代表院と、世界人口の構成を反映するくじ引きの代表を中心とする世界市民院が、地球規模の公共財について一緒に協議します。これは長期的な方向性であり、立ち上げの段階の目標ではありません。

## 9. まだ答えの出ていない問い

この憲章は、作業のための仮説です。たとえば次の問いは、まだ開かれています。

- くじ引きで選ばれた数千人が、どうすれば世界を信頼できる形で代表できるのか。それを社会にどう説明するのか
- 国連に審議を求める前に、政策がどのような「基準」を満たすべきか
- 少数の大口の資金提供者に頼らずに、どう資金をまかなうか
- 地球規模の熟議を、地域や国の熟議とどうつなぐか

最初の試行は、これらの問いを確かめるために設計します。

## おわりに

この憲章の目的は、国家をなくすことでも、大国を締め出すことでも、国連に取って代わることでもありません。21世紀の問題、つまり**それぞれの国が合理的に行動した結果が、人類全体にとって害になりうる**という問題に応えることです。

今の世界には、国家も、企業も、大学も、国際機関もあります。欠けているのは、人類全体の利益から選択肢をつくり、試し、市民が判断できるようにする常設の制度です。ここで示す回路の最初の役割は、国家に代わって世界を治めることではありません。研究、試行、熟議を通じて、**国家がまだ考えていない選択肢がある**ことを示すことです。国家どうしの外交は、その後に続きます。
