# 連載「地球のOSを書き換える」：全体の案内と目次


気候危機について、私たちはもう十分に知っています。科学者は何十年も警告を続け、世界中で多くの人が声を上げ、莫大な資金が投じられてきました。それでも化石燃料の消費は減らず、炭素の価格づけは何度も撤回されてきました。

この連載は、その理由を「努力が足りないから」とは考えません。**拡大するほど得をするという経済のルールをそのままにして、努力だけで減らそうとしてきたから**だと考えます。そして、そのルールそのものを書き換える仕組み、**Planetary OS（プラネタリーOS）**の設計図を、全8回で描きます。

---

## この連載で描くもの

Planetary OS は、地球の物理的な限界の内側で社会を回し続けるための、社会の「動作ルール」です。目指すのは、**減らすほど得をする社会**です。

これまでの取り組みの前には、2つの壁がありました。

- **壁①：今の人だけが負担する**：値上がりが今の家計を直撃し、支持が失われる
- **壁②：自分だけ減らすと損をする**：個人・企業・国のどれにとっても、一人だけ減らすのは損になる

Planetary OS は、この2つの壁を越える条件を、最初から組み込みます。

| モジュール | 役割 |
|---|---|
| 1. ストック会計とBEI | 過去の排出から恩恵を受けた側が、薄く広く負担する。長く残る基金（PTE）として運用する |
| 2. SAS | 化石燃料の上流に、一方向にしか動かない上限をかけ、排出枠を競売で売る |
| 3. 清算と還元 | 競売収入の9割を市民に直接還す。少なく使う人ほど多く受け取り、多数派保証ルールで、少なくとも7割の人の手取りがプラスになるようにする |
| 4. 改ざん防止とルール変更 | 科学的な裏付けと市民の代表の承認という「二重の鍵」で、後戻りを防ぐ |

目標は、**2℃を確実に下回ること**です。世界政府を待つのではなく、**参加すると得をし、参加しないと損をするクラブ**として、国々に広げていきます。

なお、この連載で示す制度の名前や比率、数値は、すべて「この方向が良いのではないか」を考えてもらうための**一例**です。具体的な設計は、科学的な検討と民主的な議論を経て決めるべきものだと考えています。

## 各回の案内

### 第1回　なぜ「これだけ頑張っても世界は変わらない」のか
[第1回　なぜ「これだけ頑張っても世界は変わらない」のか →](part-1.md)

これだけの資源と善意が注がれても、世界が変わらなかったのはなぜか。原因は、能力や善意の不足ではなく、エネルギーを注ぐ「宛先」がずれていたこと、そして移行先の設計図を誰も描いてこなかったことにあります。さらに深い原因として、「拡大するほど得をする」という経済のルールを見つめます。

### 第2回　地球の新しいOS「Planetary OS」の全体像
[第2回　地球の新しいOS「Planetary OS」の全体像 →](part-2.md)

設計図の全体を、一枚の地図として広げます。新しいOSに求められる4つの条件、それを書く開かれた場（PPA）、4つのモジュールと2つのお金の流れを紹介します。「それは管理社会では？」という懸念にも答えます。

### 第3回　政治の先送りを止める装置「SAS」
[第3回　政治の先送りを止める装置「SAS」 →](part-3.md)

化石燃料の上限を、毎年自動で引き下げていく仕組みです。1.5℃ではなく「2℃を確実に下回る」に目標を置き直し、なぜ価格ではなく上限なのか、なぜEUにもできなかったことができるのかを考えます。鍵になるのが、2つの壁と、それを越える2つの条件です。

### 第4回　将来世代の声を意思決定に組み込む
[第4回　将来世代の声を意思決定に組み込む →](part-4.md)

気候危機の影響を最も受けるのは、まだ投票できない世代です。未来代表議会、仮想の将来市民、くじ引きで選ぶ世界市民会議、子どものための将来信託という4つの仕組みで、「今」と「未来」の両方を代表する民主主義を考えます。

### 第5回　「我慢」ではなく「得」で動く：減らすほど得をする還元の設計
[第5回　「我慢」ではなく「得」で動く →](part-5.md)

集めたお金を、どう社会に還すのか。なぜ政府ではなく市民に直接還すのか、監視社会にならずに公平に測れるのか、実際にいくらになるのかを、具体的に設計します。日本の試算では、4人家族で年約45万円になります。企業と地域への報酬、将来の「縮小行動ポイント」も扱います。

### 第6回　世界政府なしで、どう世界に広がるのか
[第6回　世界政府なしで、どう世界に広がるのか →](part-6.md)

一国だけが厳しい上限を設ければ、産業は他国に流れます。国どうしの囚人のジレンマを、「参加すると得をし、参加しないと損をする」クラブで解きます。クラブの規模に応じて上がる削減率、先に動く国ほど有利なルール、過去の負債を元手にした基金と保証、先進国にとっての得を描きます。

### 第7回　なぜ今までの運動は勝てなかったのか：請願から実装へ
[第7回　請願から実装へ →](part-7.md)

炭素税と配当は、ずっと前からあった考え方です。それでも敗れてきた仕組みに共通する6つの弱点を振り返ります。そのうえで、運動の向け先を、政治への「お願い」から、動く仕組みを先につくって示す「実装」へと切り替えることを提案します。

### 第8回（最終回）　最初の一歩：仕様書と、それを担う若者たち
[第8回　最初の一歩 →](part-8.md)

一つの構想を、どうすれば世界を巻き込む運動に変えられるのか。担い手としての若者主導の地球市民会議（Youth GCC）、最初の一歩となる3つのステップ、仕様書から社会への実装までの4つの段階、そして読んだあなたにできることを示します。
